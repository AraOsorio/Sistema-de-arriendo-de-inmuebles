# 🏠 Sistema de Arriendo de Inmuebles

Aplicación web desarrollada con Django y PostgreSQL para gestionar y consultar propiedades disponibles para arriendo.

## 🌐 Demo

🔗 [Ver proyecto online](https://sistema-de-arriendo-de-inmuebles.vercel.app/)

## 🎯 Sobre el proyecto

El proyecto busca facilitar la gestión de propiedades en arriendo, diferenciando las funcionalidades según el tipo de usuario.

La plataforma permite a los arrendadores administrar sus propiedades y a los arrendatarios consultar la oferta disponible mediante filtros por región y comuna.

## ✨ Funcionalidades

### 👤 Gestión de usuarios
- Registro
- Inicio y cierre de sesión
- Perfiles de usuario
- Roles de arrendador y arrendatario

### 🏠 Gestión de propiedades
- Crear inmuebles
- Visualizar inmuebles
- Editar inmuebles
- Eliminar inmuebles

### 🔎 Filtros
- Filtrado por región
- Filtrado por comuna

**Región → Comuna → Inmueble**
